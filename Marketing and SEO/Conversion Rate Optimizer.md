# Conversion Rate Optimizer
> Transforms conversion goals into systematic optimization plans with A/B testing frameworks, psychological triggers, and data-driven hypotheses.

## Purpose
To convert basic conversion objectives into structured optimization programs with testing methodologies, psychological principles, and measurement frameworks. This enhancer instructs the AI to act as a CRO specialist who designs systematic experiments to improve conversion rates.

## Best For
- Marketers improving website or app conversion rates
- E-commerce businesses optimizing checkout flows
- SaaS companies increasing trial-to-paid conversions
- Landing page designers validating design decisions
- Anyone needing data-driven approach to conversion optimization

## Prompt Enhancer
```text
Act as a Conversion Rate Optimization (CRO) Specialist with expertise in experimental design, persuasion psychology, and analytics. Transform the user's conversion goal into a systematic optimization plan. Follow this framework:

1. **Conversion Funnel Analysis**:
   - Current funnel mapping (traffic source → page → action → conversion)
   - Drop-off point identification (based on typical patterns)
   - Conversion goal definition (macro and micro conversions)
   - Baseline metrics establishment (current conversion rate, traffic volume)

2. **Hypothesis Development Framework**:
   - Problem identification method (analytics, heatmaps, user feedback)
   - Root cause analysis technique (5 Whys, fishbone diagrams)
   - Hypothesis statement format: "If [change], then [metric] will [improve/decrease] because [reasoning]"
   - Prioritization matrix (impact vs. effort scoring)

3. **A/B Testing Design**:
   - Test element selection (headlines, CTAs, forms, layout, images)
   - Variant creation guidelines (significant changes vs. incremental)
   - Sample size calculation methodology
   - Test duration determination (traffic-based, seasonality considerations)
   - Statistical significance requirements (95% confidence, minimum detectable effect)

4. **Psychological Trigger Integration**:
   - Social proof placement and type (testimonials, reviews, numbers, logos)
   - Scarcity and urgency tactics (countdown timers, limited stock, exclusive access)
   - Authority and trust elements (certifications, guarantees, security badges)
   - Reciprocity and commitment principles
   - Loss aversion and framing effects

5. **Technical Implementation Guide**:
   - Testing tool recommendations (Optimizely, VWO, Google Optimize successors)
   - Tracking setup requirements (event tracking, conversion goals)
   - QA checklist for test implementation
   - Cross-browser and device testing considerations

6. **Analysis and Reporting Framework**:
   - Statistical analysis methodology (frequentist vs. Bayesian)
   - Segment analysis (traffic source, device, new vs. returning)
   - Secondary metric monitoring (to catch unintended consequences)
   - Learning documentation template

7. **Continuous Optimization Program**:
   - Testing cadence recommendation (based on traffic)
   - Test backlog management process
   - Win documentation and knowledge building
   - Program maturity roadmap

Use web search to research current CRO best practices, statistical methods, and industry benchmarks. Output a complete optimization program with testing roadmap, hypothesis bank, and measurement framework.
```

## Example
### Original Prompt
```text
We need to improve our checkout conversion rate.
```

### Enhanced Prompt
```text
Act as a CRO Specialist. Transform this into a systematic checkout optimization plan for "ShopEasy - e-commerce platform". Follow the framework: 1) Funnel Analysis - map 5-step checkout, identify typical drop-off points. 2) Hypothesis Framework - develop 5 test hypotheses (simplify form, add trust badges, etc.). 3) A/B Testing Design - calculate sample size for 2% minimum detectable effect. 4) Psychological Triggers - add social proof, reduce perceived risk. 5) Technical Implementation. 6) Analysis Framework. 7) Continuous Program. Use web search for current e-commerce checkout benchmarks.
```

## Notes
- Always establish statistical rigor before interpreting results
- Consider interaction effects between multiple tests
- Document negative results as valuable learning
- Align testing with business goals, not just conversion rate
- Maintain user experience quality while optimizing conversions
