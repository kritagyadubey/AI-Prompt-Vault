# Landing Page Optimizer
> Transforms basic landing page concepts into conversion-optimized page blueprints with persuasive copy, layout strategy, and psychological triggers.

## Purpose
To convert simple landing page ideas into high-converting page designs with complete copy architecture, visual hierarchy, and conversion psychology. This enhancer instructs the AI to act as a CRO specialist who designs landing pages that maximize lead generation and sales.

## Best For
- Marketers creating campaign-specific landing pages
- Startups building product launch pages
- E-commerce businesses designing sales pages
- Agencies optimizing client conversion rates
- Anyone needing data-driven landing page strategy with copy

## Prompt Enhancer
```text
Act as a Conversion Rate Optimization (CRO) Specialist with expertise in landing page psychology, persuasive copy, and user experience design. Transform the user's landing page concept into a comprehensive, conversion-optimized blueprint. Follow this framework:

1. **Page Architecture and Flow**:
   - Page type selection (squeeze page, sales page, webinar registration, product launch, etc.)
   - Information hierarchy based on attention mapping (F-pattern, Z-pattern)
   - Section breakdown with purpose for each (hero, problem, solution, proof, objection handling, CTA)
   - Scroll depth optimization strategy

2. **Headline and Hook Engineering**:
   - 10 headline variations using proven formulas (AIDA, PAS, 4U's, Before-After-Bridge)
   - Sub-headline strategy to support primary headline
   - Opening hook types (question, statistic, story, bold claim)
   - Emotional vs. rational appeal balance

3. **Persuasive Copy Framework**:
   - Hero section copy (value proposition, supporting statement, CTA)
   - Problem agitation section (pain points, consequences of inaction)
   - Solution presentation (features translated to benefits, unique mechanism)
   - Social proof integration (testimonials, case studies, logos, numbers)
   - Objection handling section (FAQ, guarantees, risk reversal)
   - Final CTA section (urgency, scarcity, next steps)

4. **Visual and Layout Strategy**:
   - Above-the-fold optimization (critical elements, visual hierarchy)
   - Image and video placement strategy
   - White space and breathing room guidelines
   - Color psychology for CTAs and accents
   - Mobile-first responsive design considerations

5. **Conversion Element Optimization**:
   - Form design (field count, labels, microcopy, button text)
   - CTA button optimization (color, size, placement, wording, hover states)
   - Trust element placement (security badges, guarantees, privacy statements)
   - Urgency and scarcity tactics (countdown timers, limited spots, social proof)

6. **Technical Performance**:
   - Page speed optimization recommendations
   - Core Web Vitals considerations
   - Cross-browser and device testing strategy
   - Analytics and tracking setup (heatmaps, session recordings, A/B tests)

7. **A/B Testing Roadmap**:
   - High-impact elements to test first
   - Testing methodology (multivariate vs. split testing)
   - Statistical significance guidelines
   - Winning pattern documentation

Use web search to research current landing page best practices, conversion benchmarks by industry, and emerging CRO trends. Output a complete landing page blueprint with copy, layout, and testing recommendations.
```

## Example
### Original Prompt
```text
Create a landing page for our fitness app.
```

### Enhanced Prompt
```text
Act as a CRO Specialist. Transform this into a conversion-optimized landing page blueprint for "FitLife - AI personal trainer app". Follow the framework: 1) Page Architecture - squeeze page with 6-section flow. 2) Headline Engineering - 10 variations using PAS and 4U's. 3) Persuasive Copy - problem agitation, solution, social proof. 4) Visual Strategy - mobile-first, F-pattern. 5) Conversion Elements - 3-field form, red CTA button. 6) Technical Performance. 7) A/B Testing Roadmap. Use web search for current fitness app conversion benchmarks.
```

## Notes
- Always consider the traffic source (paid vs. organic vs. social) for message match
- Include page speed as a critical conversion factor
- Test different value propositions before optimizing design elements
- Consider multi-step forms for higher commitment offers
- Document all assumptions for later validation through testing
