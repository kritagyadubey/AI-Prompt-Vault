## What is AI Prompts Vault?

**AI Prompts Vault** is a massive, high-quality, open-source collection of **Prompt Enhancers** — reusable expert prompt-engineering systems that transform simple, vague, or incomplete prompts into dramatically more detailed, structured, and actionable versions.

This is not a software tool. **This is a prompt library.** No installation. No configuration. No dependencies. Just open-source prompts that make your AI interactions dramatically more effective.

**The problem:** Most people use AI with prompts like "Write me a business plan" and get generic, shallow results.

**The solution:** A Prompt Enhancer takes your simple idea and tells the AI exactly how to expand it into something detailed, structured, and professional — before you ever ask for the actual work to be done.

---

## How It Works

```
YOUR PROMPT
---
PROMPT ENHANCER
```

That's it. That's the entire workflow.

### Step-by-Step

```
YOUR SIMPLE PROMPT
        ↓
    ADD ---
        ↓
PASTE A PROMPT ENHANCER
        ↓
    SEND TO ANY AI
        ↓
GET A DRAMATICALLY DETAILED PROMPT
```

### The Rule

> **Your original prompt goes FIRST.**
> **The `---` separator comes AFTER it.**
> **The Prompt Enhancer goes BELOW `---`.**

Everything **above** `---` is your idea. Everything **below** `---` is the expert instruction that tells the AI how to transform your idea into something much better.

---

## Quick Start

### 1. Write Your Prompt

```
Create a website for my business.
```

### 2. Add the Separator

```
Create a website for my business.

---
```

### 3. Paste a Prompt Enhancer

```
Create a website for my business.

---
[CHOOSE ANY ENHANCER FROM THE LIBRARY AND PASTE IT HERE]
```

### 4. Send to Any AI

Paste the entire block into **ChatGPT**, **Claude**, **Gemini**, **Llama**, or any other AI.

### 5. Get Your Enhanced Prompt

The AI will read your simple prompt above `---`, apply the expert transformation instructions below `---`, and return a **dramatically more detailed version** of your original prompt — ready to be used as-is or further refined.

### Example 2: Writing

<details>
<summary><strong>Before</strong></summary>

```
Write a blog post about machine learning.
```

</details>

<details open>
<summary><strong>After</strong></summary>

```
Write a 1200-1800 word blog post about machine learning for [BLOG NAME],
targeting [EXPERIENCE LEVEL] audience.

TOPIC:
Focus on [SPECIFIC ANGLE — e.g., "practical applications of ML in everyday
products"] rather than covering the entire field. Choose ONE specific angle.

TARGET AUDIENCE:
[EXPERIENCE LEVEL — e.g., "Software developers with basic programming
knowledge but no ML background"]

TONE AND STYLE:
- Informative and approachable, not academic
- Use concrete examples and analogies, not abstract theory
- Address the reader directly ("you")
- Define technical terms inline on first use

STRUCTURE:
- Title: specific, descriptive, under 60 characters for SEO
- Introduction: 150-200 words, hook the reader, state what they will learn
- Body: 3-5 main sections with H2 headings, each covering one key concept
- Conclusion: 100-150 words, summarize key takeaways, include a CTA

SEO REQUIREMENTS:
- Include "[TARGET KEYWORD]" in title, first paragraph, and 2+ subheadings
- Use semantic variations of the keyword throughout
- Include a meta description under 155 characters
- Short paragraphs (2-4 sentences)

INCLUDE:
- At least [N] concrete real-world examples
- Reference real-world tools or platforms
- Code snippets or pseudocode for technical concepts
- One "common misconception" section
- Cite [N] authoritative sources

DO NOT:
- Write a generic overview of the entire ML field
- Use a listicle format
- Include unsupported claims or made-up statistics
```

</details>

## What Makes These Enhancers Different

This is **not** a collection of "make it better" prompts.

Each enhancer is an **encoded expert prompt engineer** — a detailed, carefully crafted instruction system that knows how to:

| Capability | What It Does |
|------------|--------------|
| **Intent Analysis** | Understands what the user actually wants |
| **Task Classification** | Determines the type and domain of the request |
| **Requirement Extraction** | Pulls out explicit and implied requirements |
| **Ambiguity Detection** | Finds vague terms and multiple interpretations |
| **Context Expansion** | Adds missing context that materially improves the result |
| **Structured Output** | Organizes the enhanced prompt into clear sections |
| **Domain Awareness** | Applies domain-specific knowledge and best practices |
| **Edge Case Handling** | Considers failure modes and unusual scenarios |
| **Quality Criteria** | Defines what "excellent" means for the specific task |
| **Missing Information** | Uses placeholders, assumptions, or clarification requests |
| **Intent Preservation** | Ensures the original goal is never changed |
| **Hallucination Prevention** | Prevents the AI from inventing important facts |
| **Web Search Support** | Encourages browsing when current information helps |

## Contributing

### This project is open for contributions!

If you have a Prompt Enhancer idea — or a better version of an existing one — **we want your help.**

The process is simple:

```
Fork → Create Branch → Add Your Enhancer → Pull Request
```

### How to Add a Prompt Enhancer

1. **Fork** this repository on GitHub
2. **Create a branch** for your enhancer:
   ```bash
   git checkout -b add-my-enhancer
   ```
3. **Choose the right category** under `AI PROMPT ENHANCER/`
4. **Create your enhancer** as a `.md` file following the [file format](CONTRIBUTING.md)
5. **Open a Pull Request** with a description of what your enhancer does

That's it. If your enhancer is high-quality and useful, it gets merged.

### What Makes a Good Contribution

- A **detailed, domain-specific** enhancer (not "make it better")
- A clear **before/after example** showing the transformation
- At least **3 relevant tags** for discoverability
- **Distinct** from existing enhancers (check before creating)

### What We Don't Accept

- Weak enhancers like "improve this prompt" or "add more details"
- Duplicate enhancers that already exist in the library
- Enhancers that execute the task instead of transforming the prompt

### Full Guidelines

See **[CONTRIBUTING.md](CONTRIBUTING.md)** for the complete guide including file format, quality standards, naming conventions, and review process.
