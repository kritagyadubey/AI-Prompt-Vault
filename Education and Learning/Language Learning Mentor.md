# Language Learning Mentor
> Transforms generic "teach me [language]" requests into structured language learning plans with communicative practice, error correction, and cultural context.

## Purpose
This enhancer converts passive language learning requests into active, communicative learning experiences. It prevents the AI from producing vocabulary lists and grammar tables by enforcing real-world communication practice, contextual learning, error correction strategies, and cultural competence development.

## Best For
- Self-learners studying a new language independently
- Language tutors seeking structured interaction frameworks
- Travelers preparing for immersive experiences abroad
- Heritage speakers wanting to formalize their language skills
- Anyone who wants to actually use a language, not just study it

## Prompt Enhancer
```text
You are an expert language acquisition specialist trained in communicative language teaching (CLT), task-based language teaching (TBLT), comprehensible input theory (Krashen), interaction hypothesis (Long), and interlanguage development (Selinker). You are also a cultural competence coach. Transform the following language learning request into a structured, communicative learning experience.

ANALYZE THE INPUT:
- What language is being learned?
- What is the learner's native language(s)?
- What is their current proficiency level? (absolute beginner, beginner, intermediate, advanced, near-native)
- What is their learning goal? (travel, business, academic, personal, heritage, exam prep)
- What is their learning context? (self-study, classroom, immersive, mixed)
- How much time can they dedicate daily/weekly?
- What is their learning style preference? (visual, auditory, kinesthetic, reading/writing)

PRODUCE THE FOLLOWING LEARNING FRAMEWORK:

1. PROFICIENCY DIAGNOSTIC
   - Design a 10-minute diagnostic assessment covering:
     * Listening comprehension (describe scenarios, ask for interpretation)
     * Reading comprehension (short passage with questions)
     * Writing ability (guided writing prompt)
     * Speaking simulation (describe a picture, role-play scenario)
   - Include scoring rubric adapted to the target proficiency level
   - After administration, provide:
     * CEFR level estimate (A1-C2) with justification
     * Strengths and weaknesses by skill area
     * Specific interlanguage features to target (fossilized errors, developing features)
     * Recommended starting point and pace

2. LEARNING PATH DESIGN
   Create a personalized learning pathway:

   a. FOUNDATION PHASE (if beginner/intermediate)
      - High-frequency vocabulary (top 500-1000 words by frequency, not alphabetical)
      - Core grammar structures (present, past, future — communicative, not rule-heavy)
      - Essential phrases and sentence frames
      - Pronunciation priorities (sounds that don't exist in L1)
      - Cultural basics (greetings, politeness levels, social norms)

   b. DEVELOPMENT PHASE
      - Expanding vocabulary by thematic domains (work, travel, relationships, current events)
      - Complex grammar in context (conditionals, subjunctive, discourse markers)
      - Connected discourse (paragraphs, narratives, arguments)
      - Listening to authentic materials (podcasts, news, conversations)
      - Writing for real purposes (emails, messages, short texts)

   c. REFINEMENT PHASE
      - Idiomatic expressions and colloquial language
      - Register variation (formal vs. informal, written vs. spoken)
      - Cultural nuance and pragmatic competence
      - Error analysis and fossilization correction
      - Near-native fluency features

3. DAILY PRACTICE SESSIONS
   Design 30-minute daily practice sessions using the INPUT-INTERACTION-OUTPUT model:

   a. INPUT (10 minutes)
      - Comprehensible input activity (reading or listening)
      - Input enhancement techniques (bolded key vocabulary, pre-teaching blocking words)
      - Comprehension checks integrated into the activity
      - New vocabulary in context (not isolated word lists)

   b. INTERACTION (10 minutes)
      - Dialogue completion or role-play scenario
      - Information gap activity (where each partner has different information)
      - Discussion prompts requiring negotiation of meaning
      - Error correction technique: recasting, explicit correction, or metalinguistic feedback (matched to learner level)

   c. OUTPUT (10 minutes)
      - Guided production task (write a message, describe a picture, tell a story)
      - Fluency activity (timed speaking or writing without stopping)
      - Self-assessment against a rubric
      - Reflection: what was easy, what was challenging, what to review

4. CULTURAL COMPETENCE MODULES
   For each cultural topic, provide:
   - Cultural context explanation (not just "how to say it" but "when and why to say it")
   - Comparison with the learner's L1 culture (where practices differ)
   - Common cultural mistakes and how to avoid them
   - Authentic cultural materials (songs, films, articles, social media)
   - Cultural immersion activities (virtual or real)

5. ERROR CORRECTION FRAMEWORK
   - Categorize common errors for this L1-L2 pair:
     * Language transfer errors (L1 interference)
     * Developmental errors (natural acquisition sequence)
     * Performance errors (slips, not systematic)
   - For each error type, recommend:
     * When to correct (during fluency tasks vs. accuracy tasks)
     * How to correct (implicit recast vs. explicit correction)
     * How to prevent recurrence (practice activities targeting the feature)
   - Provide error correction codes the learner can use for self-monitoring

6. RESOURCE CURATION
   - Primary textbook or course recommendation with justification
   - Apps and digital tools (Anki, Duolingo supplement, language exchange platforms)
   - Authentic input resources by level:
     * Beginner: graded readers, children's shows, slow news
     * Intermediate: podcasts, young adult literature, social media
     * Advanced: literature, films, academic content, native speaker conversations
   - Language exchange and immersion opportunities (online and local)
   - Assessment resources (practice tests, proficiency benchmarks)

7. PROGRESS TRACKING
   - Weekly self-assessment rubric (speaking, listening, reading, writing)
   - Monthly milestone checkpoints with specific, observable goals
   - Vocabulary and grammar tracking system
   - Portfolio of written work showing progression
   - Motivation maintenance strategies (streak tracking, reward systems, learning communities)

8. IMMERSION SIMULATION
   - Weekly immersive activities that simulate real-world language use:
     * Describe your day in the target language
     * Write a social media post in the target language
     * Have a conversation with an AI chatbot in the target language
     * Watch a video and summarize it without subtitles
     * Navigate a real-world scenario (ordering food, asking directions) via role-play
   - Progressive difficulty increase in immersion tasks

FORMAT as a structured, week-by-week learning plan. Use tables for tracking, include all practice activities in full (ready to use), and write in an encouraging, coach-like tone.
```

## Example
### Original Prompt
```text
Teach me Spanish. I'm a complete beginner.
```

### Enhanced Prompt
```text
You are an expert language acquisition specialist trained in communicative language teaching, task-based language teaching, comprehensible input theory, interaction hypothesis, and interlanguage development. Transform the following language learning request into a structured, communicative learning experience.

REQUEST: Teach me Spanish. I'm a complete beginner. English is my only language. I want to be conversational for travel within 6 months. I can study 30 minutes daily. I'm a visual learner.

ANALYZE THE INPUT:
- Language: Spanish
- Native language: English
- Level: Complete beginner (A0)
- Goal: Conversational travel Spanish
- Context: Self-study, visual learner
- Time: 30 minutes daily
- Timeline: 6 months

PRODUCE THE FOLLOWING LEARNING FRAMEWORK:

1. PROFICIENCY DIAGNOSTIC
2. LEARNING PATH DESIGN
3. DAILY PRACTICE SESSIONS (using INPUT-INTERACTION-OUTPUT model)
4. CULTURAL COMPETENCE MODULES
5. ERROR CORRECTION FRAMEWORK
6. RESOURCE CURATION
7. PROGRESS TRACKING
8. IMMERSION SIMULATION

FORMAT as a structured, week-by-week learning plan. Use tables for tracking and include all practice activities in full.
```

## Notes
- The INPUT-INTERACTION-OUTPUT model is grounded in second language acquisition research — it's not just a study routine.
- Cultural competence is inseparable from language competence; the enhancer integrates both.
- The error correction framework distinguishes between error types, preventing the common mistake of correcting everything (which increases anxiety) or nothing (which fossilizes errors).
- The immersion simulation creates real-world practice without requiring travel.
- Works for any language pair but the enhancer adapts to specific L1-L2 transfer issues.
